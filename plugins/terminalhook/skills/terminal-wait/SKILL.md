---
name: terminal-wait
description: Start and interact with local commands using TerminalHook when waiting for known terminal output conditions, server readiness, build markers, or input responses would otherwise require repeated terminal checks.
---

Use `run_until` to launch a command with `program`, argument array, absolute `cwd`, and `until: [{"name":"ready","pattern":"..."}]`. Await the single call; waiting and output matching happen locally. Do not poll shell/status tools while a wait is pending.

For a noninteractive long task in the desktop app, use `submit_task` with the same command, output rules, and timeout as `run_until`. Omit `session_id` and `turn_id`; the plugin's trusted PreToolUse hook injects the actual chat context. Both `on_match` and `on_timeout` must be `terminate` (the default). For completion by natural exit, use a specific marker the command will never emit and check the returned exit code after continuation. After `submitted`, end the turn immediately with a short handoff message. Do not call `functions.wait`, `wait_output`, shell/status tools, or emit periodic updates. The synchronous Stop hook calls `await_tasks` locally, waits on task events, and continues the agent once with results. `prepare_task`, `await_tasks`, and `audit_event` are host hook tools; never call them from the model. If submission reports missing hook context, stop and ask the user to review the plugin hooks in the desktop app; do not invent session IDs or silently fall back to polling. Hook waits require a live MCP connection and remain subject to hook/server timeouts. Existing `run_until` workflows remain available for interactive services.

- There is no implicit shell. Invoke `pwsh -NoProfile -Command` or `cmd.exe` explicitly for shell syntax and Windows `.cmd` files.
- TerminalHook sends and decodes UTF-8. Before PowerShell text I/O, dot-source [scripts/Initialize-Utf8.ps1](scripts/Initialize-Utf8.ps1) in the target session: `pwsh -NoProfile -Command ". '<absolute path to this skill>/scripts/Initialize-Utf8.ps1'; <command>"`. This sets `Console.InputEncoding`, `Console.OutputEncoding`, and `$OutputEncoding` to UTF-8 without a BOM, including Windows PowerShell 5.1 and native command pipelines. Resolve the script from this skill's installed location; use the same prefix before invoking a `.ps1` file. Running the initializer in a separate process does not configure the target session. For a standalone MCP installation without this skill, set those three values explicitly before the command.
- Choose a specific output marker. A match proves that condition occurred, not that the process exited successfully.
- Default `on_match` and `on_timeout` terminate the command. For a service or interactive program, pass `on_match: "keep_running"`. Retain the returned `process_id` and `cursor`; call `stop_process` when finished.
- To wait for a later condition, call `wait_output` with that `process_id`, the previous `cursor`, and new `until` rules. Use `cursor`, not `latest_cursor`, to avoid skipping data already received after the previous match. Do not calculate or reuse cursors across processes. `cursor_expired` means buffered history was lost: inspect logs/diagnostics before explicitly choosing a new start.
- For input, call `write_input` with `data` and optionally `wait: {"until":[...],"timeout_ms":...}`. The output cursor is registered before sending, preventing a race with immediate responses. Include newline explicitly. Pipe EOF can be sent with `eof: true`.
- Pipe mode preserves stdout/stderr separately. Use `mode: "pty"` for programs requiring a real terminal; output is then a merged `terminal` source, input can be echoed, and Enter is typically `\r`. PTY EOF is application-specific.
- Default line matching includes unfinished lines, removes ANSI CSI/OSC, and normalizes CR/LF. `$` means the end currently observed. Use a delimiter for complete variable-length captures. For newline delimiters or cross-line patterns, set `match_mode: "window"` with a suitable `window_bytes` (256..262144). Output outside that bounded window is not matched.
- Rules use Rust regex syntax, without lookaround, backreferences or zero-width matches. The tool limits output returned to the model and reports any match/capture truncation explicitly.
- Set a task-appropriate `timeout_ms`, at most 600000; the packaged MCP timeout is 660 seconds. Do not automatically restart or repeatedly wait after a timeout. `wait_output` and response waits preserve the process on timeout/cancellation. Cancelling `run_until` cleans up its process.
- Results include status, natural exit code when observed, output tails, and a rotating raw `log_dir`. Set an absolute `log_dir` in `run_until` if logs must survive the connection; default logs are temporary.

Only commands launched by this MCP connection are managed. It cannot attach to Codex built-in terminal sessions or resume processes after reconnection. Commands execute with local MCP OS permissions; normal tool approval remains applicable. Closing the connection cleans up its active processes.
